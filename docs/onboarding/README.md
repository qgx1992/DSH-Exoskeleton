## 文档体系与优先级

仓库内存在多份文档，**规则冲突时按以下顺序裁决**：

```
AGENT.md（AI 协作唯一权威事实源）→ 设计文档（DEV_DOC.md / docs/*-DESIGN.md）→ 本手册 / README（导览）
```

- 本手册负责"解释"：把 AGENT.md 里浓缩的事实展开成新人能消化的路径；
- 本手册**不重复维护**硬约束（R-N 不变量、版本规则等）——这些以 AGENT.md 为准，手册只做转述并指向原文。

## 维护约定

本手册随代码演进，需要持续更新。约定：

1. 新增 `src/main` 模块、renderer 面板或 IPC 通道时，必须同步更新 [04-code-map.md](04-code-map.md)（规划中）；
2. 新增踩坑记录时，先写进 AGENT.md §7（权威事实源），再视需要转述到 06-debug.md；
3. 每份文档头部保持"面向谁 + 冲突优先级"说明，避免新人误读。

## 快速了解这个项目（30 秒版）

> DeepSeek Harness（DSH）是 DeepSeek 官方的 Agent 框架，自带 Web UI（`dsh web`），但平时要开终端手动启动。
> 本仓库做了一个 **Electron 桌面外壳**：把 `dsh web` 封装成双击即用的 Windows 程序，遵循**壳核分离**——绝不动 DSH 内核，官方升级无缝跟随；默认共用 `~/.dsh`，已有配置零迁移。
> 桌面外壳 ≈ 子进程管理 + 原生窗口/托盘 + 管理仪表盘（状态/设置/内核/档案/插件/备份/日志/更新）。

详细概念见 [01-terms.md](01-terms.md)。
